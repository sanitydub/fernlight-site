Inkwell

Notes that live on your own server.

Inkwell is a simple note-taking app you host yourself. Write in Markdown with a live preview, find anything with full-text search, and keep every note in a single SQLite file that you control, with no requests to outside services.

  • Markdown with Write, Split and Read views
  • Notebooks, #tags and [[wiki-links]] with backlinks
  • Import from Obsidian or Joplin, export any time
View on GitHub Setup guide

Free and open source (AGPL-3.0). Runs with one Docker command.
